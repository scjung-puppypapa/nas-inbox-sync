# NAS Inbox Sync

A personal, single-user tool.
It copies plain-text note files from the owner's own Google Drive to the owner's own home server.

It is not a public service. It is used by one person only and does not collect data from anyone else.

개인용 도구입니다. 소유자 본인의 구글 드라이브에 있는 텍스트 노트 파일을 본인의 홈서버로 가져옵니다. 다른 사람은 사용하지 않으며 다른 사람의 데이터를 수집하지 않습니다.
